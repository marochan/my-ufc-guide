## 2. 問題・依頼の内容・変更理由
- **問題**: GitHub Pages の自動ビルド（`actions/jekyll-build-pages@v1`）において、以下のエラーが発生してデプロイが失敗した。
  ```
  Error reading file /github/workspace/ufc/ufc334/*.md: invalid byte sequence in UTF-8
  Conversion error: Jekyll::Converters::Markdown encountered an error: The source text contains invalid characters for the used encoding UTF-8
  ```
- **変更理由**: `ufc/ufc334/*.md` の3ファイルは中身が Microsoft Word（docx/zip形式）のバイナリファイルであったため、Jekyll の Markdown パーサー（kramdown）が UTF-8 テキストとしてパースできずにエラーを起こしていた。また、本プロジェクトはルートにある静的ファイル `index.html` のみで完結しているため、Jekyll による Markdown 変換処理自体が不要であった。

## 3. 実際に変更した内容と主なファイル

- **初稿ファイルの拡張子修正**:
  - `ufc/ufc334/*.md`（実体が docx のバイナリ）の拡張子を正しい形式 `.docx` にリネーム。
